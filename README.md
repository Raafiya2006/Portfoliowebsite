# Raafiya Afzal — Portfolio

A cinematic, scroll-driven personal portfolio built with Three.js and WebGL.

## ✨ Features
- Live 3D scene with animated phoenix bird and flying ship
- Smooth scroll-based camera journey through the sky
- 7 sections covering work, skills, projects and contact
- Fully responsive with gold accent typography

## 🛠️ Built With
- Three.js (3D rendering & animation)
- WebGL / GLSL shaders (custom sky & atmosphere)
- Cormorant Garamond + JetBrains Mono (typography)
- Vanilla HTML, CSS, JavaScript

## 🚀 Projects Featured
- Agentic AI Epidemic Simulator (PyTorch, RL, LLM)
- StudySphere AI Platform (MERN Stack, NLP)
- Earthly Eats (Hydroponic supply chain app)
- HabitFlow (Habit tracking app)
